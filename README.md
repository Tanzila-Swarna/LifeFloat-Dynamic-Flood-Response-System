# LifeFloat: Dynamic Flood Response System 

LifeFloat is a Java-based object-oriented system designed to simulate intelligent flood rescue operations. It dynamically analyzes flood conditions and efficiently manages rescue resources based on real-time factors such as water level and the number of affected people.

This project demonstrates the practical implementation of core Object-Oriented Programming (OOP) principles while solving a real-world disaster management problem.


Key Features are:

*  Water level monitoring
*  Automatic danger zone detection
*  Dynamic victim management using ArrayList
*  Smart boat allocation based on population size (capacity-based logic)
*  Shelter assignment system
*  Structured and sequential emergency reporting

OOP Concepts Used

Encapsulation → Secure handling of victim data
Inheritance → FloodEmergency extends base Emergency class
Polymorphism → Different rescue team behaviors
Abstraction → Abstract RescueTeam class

Technologies that are used-

* Java (Core Java)
* OOP Principles
* Java Collections (ArrayList)

Objective:
The goal of this project is to simulate a real-life flood rescue scenario where decisions must be made quickly and efficiently. It focuses on resource optimization, clean code structure, and scalability.

It Highlights-

* No hardcoded resource allocation
* Real life inspired logic
* Clean and modular design
* Automatic decision-making system


 How to Run

1. Compile the code:
   javac Main.java
   
3. Run the program:
   java Main

LifeFloat represents a simple yet powerful approach to building smarter disaster response systems using Java.
